# Medium digest interests

Copy this file to `STATE_DIR/interests.md` and edit it. The medium-digest skill reads it on every run.

## Interests
What you want more of. Topics, kinds of posts, authors or publications you trust.
- Backend engineering: distributed systems, databases, reliability
- AI engineering: agents, evaluation, LLMs in production, research with real results

## Skip
Titles matching these are dropped from the digest entirely. The agent matches the intent, not the exact wording. The skill also has built-in patterns for listicles, hustle posts, writing about Medium, and clickbait framing.
- I tried N+ courses/tools/books …
- Personal-essay life lessons
- Anything about earning money, side hustles or passive income
