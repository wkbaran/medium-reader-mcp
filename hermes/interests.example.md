# Medium digest interests

Copy this file to `interests.md` in the digest directory (`MEDIUM_READER_DIGEST_DIR`) and edit it. The medium-reader server reads it on every digest run.

## Interests
What you want more of. Topics, kinds of posts, authors or publications you trust. Shown to the agent when it shortlists, and to the title rater as context.
- Backend engineering: distributed systems, databases, reliability
- AI engineering: agents, evaluation, LLMs in production, research with real results

## Skip
Titles matching these are dropped before the agent sees them. A model rates every title against this list by intent, not exact wording, so describe patterns rather than keywords. There's no built-in list: without this section nothing is skipped.
- I tried N+ courses/tools/books …
- N best / Top N … (roundups and listicles)
- Anything about earning money, side hustles or passive income
- Writing about writing on Medium (earnings, followers, account bans)
- Personal-essay life lessons
- Clickbait framing: "Nobody tells you", "will change your life", "You're using X wrong", "Stop using X", "X is dead"
